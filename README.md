# نظام إدارة المخبز | Bakary

نظام عربي RTL لإدارة المخبز، مبني باستخدام **Flask + Python + PostgreSQL + Flask-SQLAlchemy + Flask-Migrate**، مع واجهة Mobile-First وPWA وصلاحيات مفصلة حسب الدور.

## الحالة الحالية

بدأ المستودع فارغًا. اكتملت وثائق المتطلبات وقواعد العمل، وأُضيف الهيكل الأولي لـ Flask والنماذج الأساسية وإعدادات PostgreSQL وملفات migration وPM2 واختبار الصحة. لا يزال تشغيل الاختبارات والتحقق من الاتصال والترحيل الفعلي مطلوبًا قبل اعتبار المرحلة الأولى مكتملة.

## التقنية والبنية المستهدفة

- Flask App Factory وتقسيم الوحدات باستخدام Blueprints.
- نماذج SQLAlchemy ضمن حزمة models منظمة، وكائن قاعدة بيانات مشترك `db` وإدارة جلسات موحدة.
- Flask-Migrate/Alembic لجميع تغييرات المخطط؛ لا تعدّل قاعدة الإنتاج يدويًا.
- PostgreSQL محليًا: قاعدة `bakary`، مستخدم `bakary`، وكلمة مرور التطوير المطلوبة `bakary`. تحفظ بيانات الاتصال في ملف بيئة محلي غير مرفوع إلى Git.
- Gunicorn خلف PM2 على المنفذ `4043`.
- واجهات Jinja2 وBootstrap RTL مع CSS/JavaScript للمكونات المخصصة، وPWA قابلة للتثبيت.
- تصميم Mobile-First مستلهم بصريًا من لوحة مشروع [water-pos-postgres](https://github.com/zydan25/water-pos-postgres)، مع أيقونات ومحتوى يناسبان المخبز.
