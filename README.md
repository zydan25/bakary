# نظام إدارة المخبز | Bakary

نظام عربي RTL لإدارة المخبز، مبني باستخدام **Flask + Python + PostgreSQL + Flask-SQLAlchemy + Flask-Migrate**، مع واجهة Mobile-First وPWA وصلاحيات مفصلة حسب الدور.

## الحالة الحالية

المستودع يضم خطة تنفيذ وقواعد عمل مفصلة وهيكلًا تأسيسيًا للتطبيق. توجد ترحيلات Alembic للجداول الأساسية والنماذج التشغيلية، مع إعدادات Flask والمصادقة والصلاحيات الأساسية وقوالب RTL وManifest للـ PWA وPM2. **لم تُثبت بعد جاهزية التشغيل**: يجب تطبيق الترحيلات على PostgreSQL وتشغيل الاختبارات ومراجعة نتائج CI قبل اعتبار المرحلة التأسيسية مكتملة.

## التقنية والبنية

- Flask App Factory وتقسيم الوحدات إلى Blueprints.
- نماذج SQLAlchemy ضمن `app/models/`، وكائن `db` مشترك وجلسات موحدة.
- Flask-Migrate/Alembic لجميع تغييرات المخطط؛ لا تعدّل قاعدة الإنتاج يدويًا.
- PostgreSQL محليًا: قاعدة `bakary`، مستخدم `bakary`، وكلمة مرور التطوير المطلوبة `bakary`. تحفظ بيانات الاتصال في ملف بيئة محلي غير مرفوع إلى Git.
- Gunicorn خلف PM2 باسم `bakary` على المنفذ `4043`.
- واجهات Jinja2 وBootstrap RTL مع CSS/JavaScript للمكونات المخصصة، وPWA قابلة للتثبيت.
- تصميم Mobile-First مستلهم بصريًا من مشروع [water-pos-postgres](https://github.com/zydan25/water-pos-postgres)، مع محتوى وأيقونات تناسب المخبز.
