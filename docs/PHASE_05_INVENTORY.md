# المرحلة 5 — المخزون والمواد الخام

**الفرع:** `main`

## المنجز
- سجل مواد خام بالاسم والرمز ووحدة القياس وحد تنبيه المخزون.
- صفحة بطاقات للمواد مع البحث وحالة التفعيل والرصيد الحالي والتنبيه عند انخفاضه.
- نموذج رصيد افتتاحي أو إضافة مخزون بتاريخ وبيان.
- دفتر حركات مستقل؛ الرصيد الحالي يحسب من الوارد ناقص الصادر ولا يعدل مباشرة.
- منع الرصيد السالب عبر خدمة المخزون.
- صفحة حركة المادة مرتبة بالأحدث وتعرض الوارد والصادر والبيان.
- ربط استهلاك الدقيق في الإنتاج بحركات المخزون.

## المتبقي
- نموذج تكلفة شراء/تكلفة الوحدة والتقييم المالي للمخزون.
- اختبار طلبات مخزون متزامنة على PostgreSQL الفعلي.
- اختبار واجهات الهاتف في متصفح فعلي.
