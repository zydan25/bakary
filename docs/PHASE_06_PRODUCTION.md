# المرحلة 6 — العجنات والإنتاج

**الفرع:** `main`

## المنجز
- سجل العجنات حسب التاريخ والفترة والصنف والكمية المنتجة والبيان.
- الصنف الافتراضي محدد عند فتح النموذج ويمكن تغييره.
- طريقتان لتسجيل استهلاك الدقيق: لكل عجنة أو إجمالي الفترة.
- ربط العجنة بمادة الدقيق عبر migration `20261014_0004_dough_flour_item.py`.
- خصم الدقيق من دفتر المخزون ضمن transaction تسجيل العجنة نفسها.
- منع خلط الاستهلاك الفردي والإجمالي للمادة والفترة نفسيهما.
- استخدام idempotency key لمنع تكرار العجنة أو خصم الدقيق مرتين.
- ملخص إنتاج الفترة والإنتاج حسب الصنف وإجمالي الدقيق المسجل.
- اختبارات تغطي رصيد المخزون بعد الاستهلاك، ومنع التكرار، ومنع خلط طريقتي الدقيق، وعرض الصفحات.

## المتبقي
- إقفال الفترة وترحيل المتبقي للافتتاحية التالية ضمن المرحلة 7.
- اختبارات التزامن والمعاينة اليدوية على الهاتف.
